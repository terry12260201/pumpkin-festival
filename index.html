選禮顧問

每年由 AI 上網研究一次，只用最近兩年的資料。老闆看預算與 CP 值，員工看心意與比較。

賀圖工作台

選節慶與風格 → 複製咒語 → GPT 出主視覺 → Canva 排成明信片。做好的連結記回紀錄裡。

設定

有設定 Claude API 金鑰時，「產生咒語」會由 AI 依節慶、風格、今年禮盒即時撰寫，每次不同；沒有金鑰就用內建範本。

怎麼做（約 10 分鐘）

  1. 複製「GPT 生圖咒語」，雙擊桌面的 GPT生圖.command 貼上，圖會存到桌面。
  2. 把「Canva 排版咒語」貼給 Claude（要開 Canva 連接器），它會建明信片、放 Logo、放祝福語、匯出 PNG／PDF。
  3. 把 Canva 連結貼回「紀錄」的賀卡那一列，明年就找得到。
  4. 要印：A6 明信片 300dpi，出血 3mm；要傳：PNG 1:1 或橫幅。
  5. 要做影片：複製「④ 影片咒語」貼給南瓜中控的 AI 影片工坊（15 秒、16:9、左下角白色 Logo），之後接其他影片工具的 MCP 也用同一段。

按「產生咒語」就會出現四段可複製的內容：GPT 生圖、Canva 排版、卡片文案、影片咒語。

設定

沒接 Google Sheet 也能用（資料存在這台電腦的瀏覽器）。接上之後三人看同一份，並由 Apps Script 每天寄提醒。

連線 Google Sheet

Claude API（賀圖即時生成）

金鑰在 platform.claude.com → API keys 建立；每次產生約 0.1 元美金以內。

部署步驟

  1. 用公司帳號開新 Google Sheet，命名「南瓜節慶帳本」。
  2. 擴充功能 → Apps Script → 貼上 apps-script/Code.gs → 選 setup 執行一次並授權。
  3. 部署 → 新增部署 → 網頁應用程式 → 執行身分「我」、存取權「公司網域」或「任何人」→ 複製網址貼到上面。
  4. （選）專案設定 → 指令碼屬性 加 TG_TOKEN、TG_CHAT 就會發 Telegram。
  5. 編輯器跑 testReminderNow 收一封測試信，確認 Email／Calendar 都通。
