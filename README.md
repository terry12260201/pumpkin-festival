# 🎁 南瓜節慶帳本 · Pumpkin Festival Ledger

公司每年節慶「發了什麼獎金、辦了什麼活動、送了什麼禮盒給誰、花了多少、下一個什麼時候到」一頁看完的網頁工具。單檔 HTML，打開就能用；接上 Google Sheet 後多人共用、節慶前 14 天自動寄提醒。

**線上版**：https://terry12260201.github.io/pumpkin-festival/

## 三步開始
1. 打開線上版（或下載 `index.html` 雙擊）。「人員」頁「＋ 新增人員」或「貼上匯入」建名單。
2. 「紀錄 → ＋ 整批加入人員」：選節慶、填禮盒與單價、勾人，一按就是每人一列；禮盒可上傳照片。
3. 要多人共用與自動提醒：照 `apps-script/部署步驟.md` 六步接 Google Sheet（約 10 分鐘）。

## 頁籤
| 頁籤 | 做什麼 |
|---|---|
| 總覽 | 下一個節慶倒數、年度統計、歷年一覽（每年 × 每節慶）、各節慶明細與去年比較 |
| 紀錄 | 直接在格子改、篩選、依篩選加總、整批加入人員、照片、CSV 匯出／貼上匯入 |
| 人員 | 員工／外包／夥伴／廠商，送禮名單開關，人數摘要 |
| 選禮顧問 | 2025–2026 台灣企業禮盒趨勢研究（46 個來源）：流行、地雷、預算帶、老闆 vs 員工視角、DIY 組合 |
| 賀圖 | 產生 GPT 生圖／Canva 排版／卡片文案／15 秒影片分鏡四段咒語；設定 Claude API 金鑰可由 AI 即時撰寫 |
| 設定 | 接 Google Sheet、提醒天數、收件人、預算帶、節慶日期、JSON 備份 |

## 資料存在哪
- 本機模式：瀏覽器 localStorage（設定頁可匯出 JSON）。
- 共用模式：你的 Google Sheet；照片存你 Drive 的「節慶帳本_照片」資料夾。
- 線上版本身不存任何人的資料，也不含任何公司名單。
