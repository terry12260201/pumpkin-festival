# 部署步驟 v2（雲端版：登入＋Drive 歸檔）— 南瓜做，約 15 分鐘

做完後：五組公司信箱登入才看得到、資料在 Google Sheet、每個節慶自動歸檔到 你的 Drive 資料夾、Claude 金鑰只在後端、每天 09:00 提醒。

## 1. 開一張新的 Google Sheet（放在節慶帳本資料夾裡）
- 到你想放的 Drive 資料夾→ 右鍵 → Google 試算表 → 檔名改「節慶帳本_資料庫」。
（放別處也可以，setup 會自動搬進來。）

## 2. 貼兩個檔案
- Sheet 上方 **擴充功能 → Apps Script**。
- 左側 `Code.gs`：全刪，貼上 `apps-script/Code.gs`。
- 左側「＋」→ **HTML** → 檔名打 `index`（不要副檔名）→ 全刪，貼上 `apps-script/index.html`。
- 存檔（Cmd+S）。

## 3. 指令碼屬性（金鑰與名單都在這，網頁看不到）
- 左側齒輪 **專案設定** → 最下面 **指令碼屬性 → 新增**：

| 屬性 | 值 |
|---|---|
| `CLAUDE_API_KEY` | 你的 sk-ant-… |
| `ALLOWED_EMAILS` | `a@your-company.com,b@your-company.com`（之後加人改這裡） |
| `DRIVE_FOLDER_ID` | 你的 Drive 資料夾 ID |
| `TG_TOKEN` / `TG_CHAT` | 選填，要 Telegram 才填 |

## 4. 執行 setup 並授權
- 編輯器上方函式選 **`setup`** → 執行 → 授權（進階 → 前往 → 允許：Sheet、Drive、Gmail、Calendar、外部連線）。
- 回 Sheet 看：多了 6 個分頁（紀錄／節慶／人員／設定／提醒紀錄／歸檔紀錄）；Drive 資料夾裡多了「匯出」。

## 5. 部署成網頁應用程式
- 右上 **部署 → 新增部署 → 齒輪選「網頁應用程式」**
- 執行身分：**我**
- 誰可以存取：**你的公司網域內**（這樣一開就是 Google 登入，白名單再擋一層）
- 部署 → 複製 **/exec 網址**。這就是團隊的入口，可用短網址包起來。

## 6. 進去驗收
- 用你的帳號開網址：右上角出現你的名字、狀態「雲端」。
- 「人員」→「＋ 新增人員」或「貼上匯入」把 16 人貼進去（本機版「人員 → 匯出 CSV」複製整表即可）。
- 「紀錄 → ＋ 整批加入人員」建 2026 中秋 → 狀態改「已發放」→ 總覽該卡按「歸檔到雲端」→ 看到 📁📊📄 三個連結，Drive 裡出現 `2026/中秋/2026_中秋_紀錄`（Sheet＋PDF）。
- 「賀圖」→「產生咒語」→ 應顯示「由 Claude 產生」。
- 「設定」最上面「雲端版」區塊看得到登入者、Drive 連結、Claude 已設定。
- 用不在名單的帳號開網址 → 應看到「這個帳號不在名單裡」。

## 7. 把本機資料搬上來（你這次打的 2026 中秋）
- 雙擊本機 `~/節慶帳本/index.html` → 設定 → **匯出 JSON 備份**。
- 雲端版 → 設定 → **匯入 JSON** → 選那個檔。紀錄會直接進 Sheet。

## 之後
- 改程式：貼新的 Code.gs／index.html 後，**部署 → 管理部署 → 編輯 → 版本「新版本」→ 部署**，網址不變。
- 加人：改指令碼屬性 `ALLOWED_EMAILS`，不用重新部署。
- Drive 結構：`南瓜節慶帳本/年份/節慶/`（`YYYY_節慶_紀錄` Sheet＋PDF、`照片/`）、`匯出/`（手動匯出的 CSV／JSON）。
- 自動歸檔：每天 09:00，節慶日已過且該節慶全部「已發放」→ 自動產生；之後再改資料會在隔天重新歸檔一次。

## 常見問題
- 開網址出現「這個帳號不在名單裡」但明明是公司信箱 → 瀏覽器同時登入多個 Google 帳號，網址後面加 `?authuser=1` 或用無痕視窗。
- 「後端尚未設定 CLAUDE_API_KEY」→ 指令碼屬性名稱要一模一樣、值前後不要空白。
- PDF 顯示「未產生」→ 第 4 步授權時漏了 Drive 或外部連線；重跑 setup 重新授權，再按一次歸檔。
