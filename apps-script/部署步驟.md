# 部署步驟（南瓜做，約 10 分鐘）

做完這 6 步，南瓜、Peter、行政就看同一份資料，而且每天早上 9 點會自動檢查、14 天前寄提醒。

## 1. 開一張新的 Google Sheet
- 用公司帳號到 https://sheets.new
- 檔名改成「南瓜節慶帳本」。分頁不用自己建，程式會建。

## 2. 貼程式
- Sheet 上方選單：**擴充功能 → Apps Script**
- 把編輯器裡原本的內容全刪掉，貼上 `Code.gs` 全部內容，按儲存（磁片圖示）。
- 上方函式下拉選 **`setup`** → 按 **執行**。第一次會跳授權：選你的帳號 → 「進階」→ 「前往（專案名稱）」→ 允許。
- 回到 Sheet 看：應該多了 5 個分頁（紀錄、節慶、人員、設定、提醒紀錄），節慶日期已填好。

## 3. 部署成網頁應用程式
- 右上 **部署 → 新增部署 → 類型選「網頁應用程式」**
- 執行身分：**我**；誰可以存取：**南瓜虛擬科技（公司網域）**。若行政用個人 Gmail，就選「任何人」。
- 按部署 → 複製那串 **以 /exec 結尾的網址**。

## 4. 把網址貼進工具
- 雙擊 `index.html` → 上方「設定」→ 貼上網址、填你的名字 → **測試連線並同步**。
- 看到 ✅ 就是通了；右上角狀態會變「已同步」。
- 已經在本機打過的資料，按「把本機資料推上 Sheet」一次帶上去。

## 5.（選）接 Telegram
- Apps Script 左側齒輪 **專案設定 → 指令碼屬性 → 新增**：
  - `TG_TOKEN`＝Bot 的 token（可沿用公告欄 Bot）
  - `TG_CHAT`＝要收提醒的群組或個人 chat id
- 沒填就只寄 Email＋建 Calendar，不會出錯。

## 6. 測一封
- Apps Script 編輯器函式選 **`testReminderNow`** → 執行 → 信箱應收到「【節慶提醒】中秋…」、Calendar 多兩個事件。
- 之後每天 09:00 自動跑 `dailyCheck`，寄過的會記在「提醒紀錄」分頁，不重寄。

## 禮盒照片
- 接上 Sheet 後，在「紀錄」按「＋ 照片」會把圖存到你 Drive 的「節慶帳本_照片」資料夾（程式自動建），分享設為「知道連結的人可看」，這樣 Peter／行政開工具也看得到縮圖。不想公開連結就只用本機模式（縮圖存瀏覽器）。

## 收件人／預算改哪裡
- 工具的「設定」頁改完按儲存，會同步寫回 Sheet 的「設定」分頁；直接改 Sheet 也可以。
- 提前天數預設 14，改「設定」分頁的 `leadDays` 或每個節慶的 `leadDays` 欄。

## 常見問題
- **測試連線失敗**：網址要以 `/exec` 結尾；存取權若選「公司網域」，開網頁的瀏覽器要已登入公司帳號。
- **改了 Code.gs 沒生效**：要 **部署 → 管理部署 → 編輯 → 版本選「新版本」→ 部署**，網址不變。
- **Email 沒收到**：看 Apps Script 左側「執行紀錄」；「設定」分頁的 `recipients` 要有 Email。
